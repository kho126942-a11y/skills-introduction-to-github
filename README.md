1. branch 생성<br>
repository란 파일과 폴더를 포함하는 프로젝트이다.<br>
branch란 저장소의 병렬 버전이다.<br>

저장소 메뉴의 코드탭에서 main을 클릭한다.<br>
원하는 이름을 적고 create branch를 클릭한다.<br>
<img width="718" height="418" alt="image" src="https://github.com/user-attachments/assets/6d51d112-7e20-4b71-8d98-a2dc7f4ed4cf" />

2. 변경사항 커밋하기<br>
커밋이란 파일 추가/삭제/이름 변경 및 파일 내용 수정과 같은 프로젝트 변경 사항을 기록하는 것을 의미한다.<br>
<br>
add file에서 create new file을 클릭<br>

3. Pull request 생성 <br>
풀 리퀘스트를 통해 다른 사람들이 여러분의 브랜치에 있는 변경 사항을 확인하고 해당 변경 사항을 수락 또는 거부하거나 추가 변경 사항을 제안할 수 있다. <br>
